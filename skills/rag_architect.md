# Skill: RAG & Technical Knowledge Base

## Description
Indexa y consulta manuales técnicos y catálogos de herrajes usando la arquitectura Retrieval-Augmented Generation.

## Capabilities
- **Chunking Strategy:** Divide PDFs técnicos en fragmentos semánticos para evitar alucinaciones.
- **Vector Search:** Interactúa con Pinecone para recuperar solo la información necesaria para responder dudas de montaje o códigos de error.
- **Visual Citation:** Siempre pide la referencia de imagen del PDF para validar la respuesta con el manual original.
