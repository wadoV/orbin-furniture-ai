### Técnicas de painelamento e tampo
```
TAMPO-MAD   Tampo de madeira maciça — colagem de tiras (edge-glued panel)
            Largura máx por tira: 100mm (evita empenamento)
            Alternância de anéis de crescimento: ↑↓↑↓ por tira
            Adesivo: PVA D3 ou cola de osso para restaurações
            Prensa: mínimo 24h a temperatura ambiente

TAMPO-MOL   Tampo moldado (curved top)
            Laminação a quente ou a frio sobre forma
            Espessura por lâmina: 3–4mm (≤8 lâminas)

TAMPO-ENG   Tampo engenheirado (engineered wood top)
            Núcleo: MDF 25mm ou aglomerado + chapa natural 0.6mm
            Pós: laca PU 2K ou óleo de linhaça c/ cera carnaúba
```

### Processo artesanal de lixamento
```
LIXAMENTO MANUAL PROGRESSIVO:
Grit 80   → Remoção de imperfeições, nivelamento geral
Grit 120  → Uniformização da superfície
Grit 180  → Preparação para verniz/laca (última passada a favor do fio)
Grit 220  → Entre demãos de laca (lixamento leve — sem pressão)
Grit 320  → Polimento final em lacas de alto brilho
Grit 400+ → Ultra-polimento para piano finish

REGRA: Sempre lixar a favor do fio da madeira.
NUNCA lixar contra o fio — risco de arranhões visíveis no acabamento.
```

## ORÇAMENTO ARTESANAL — TABELA DE TEMPO

Uso para calcular horas-homem em projetos premium:

| Operação | Unidade | Tempo médio | Nível |
|----------|---------|-------------|-------|
| Encaixe mecha e mortisa | por encaixe | 45–90 min | Master |
| Dovetail manual | por canto | 60–120 min | Master |
| Tampo maciço colado (1m²) | por m² | 2–4 h | Senior |
| Laminação curva | por peça | 4–8 h | Senior |
| Lixamento manual completo | por m² | 1–2 h | Junior |
| Acabamento óleo (3 demãos) | por m² | 2–3 h | Junior |
| Incrustação (inlay) simples | por cm linear | 15–30 min | Master |
| Entalhamento decorativo | por dm² | 2–6 h | Master |
| Pirogravura | por dm² | 1–3 h | Artesão |

**Fórmula de precificação artesanal:**
```
Custo = (Horas × Hora/marceneiro) + (Material × 1.35) + (Overhead 25%) + (Margem 40%)
Valor artesanal = Custo × Fator_autor (1.5x–3x dependendo do renome)
```

## ALERTAS AUTOMÁTICOS DO AGENTE

Quando `artesano_pro` está ativo, Orbin deve:

1. **ALERTA EMPENAMENTO** — Se `width > 300mm` e `material = madeira maciça`: sugerir colagem em tiras ou núcleo MDF
2. **ALERTA DILATAÇÃO** — Se `hasDoors: true` e material `madeira maciça`: adicionar gap lateral mínimo 3mm (não 2.5mm) por variação sazonal
3. **ALERTA ACABAMENTO** — Se `material = madeiras nobres (nogueira, freijó, teca)`: sugerir `ACB-OIL` antes de laca
4. **SUGESTÃO ENCAIXE** — Se `numDrawers > 0` e modo artesanal: sugerir `ENC-DV` (dovetail) para gavetas de alto valor
5. **AVISO PESO** — Se `density > 900 kg/m³` (ipê, jatobá): alertar sobre peso estrutural do módulo
6. **CÓDIGO OPERAÇÃO** — Ao gerar lista de corte: incluir coluna `Operação` com código `OP-ART-xx` correspondente ao tipo de encaixe e acabamento

## INTERAÇÃO COM O PROMPT SYSTEM DE ORBIN

### Prompt para geração de lista de corte artesanal:
```
Generate a complete artisan-grade cut list and operation schedule for this furniture piece.

Manufacturing context: handcraft / semi-industrial carpentry using solid wood or premium MDF with natural veneer.

For each piece include:
- Código, Nome, Qty, L × W × T (net dimensions after joinery deductions)
- Grain direction (parallel to length unless specified)
- Edgebanding: specify type and edges (ABS 2mm / PVC 0.45mm / solid wood strip 3×20mm)
- Joinery type: specify encaixe code (ENC-MAR, ENC-DV, ENC-CAV, etc.)
- Operation code (OP-ART-xx or OP-CNC-xx)
- Finish code (ACB-xxx)

Additionally provide:
- Hardware schedule (dobradiças, corrediças, puxadores artesanais)
- Estimated man-hours by operation
- Material volume in m³ and kg (use density table)
- Waste percentage estimate (15% standard, 25% for complex joinery)
```

### Prompt para validação artesanal:
```
Validate this design for artisan-quality manufacturing:
1. Check wood movement allowances (solid wood: 3mm gap doors, not 2.5mm)
2. Verify grain direction is specified for all decorative panels
3. Flag any shelf span > 750mm in solid wood (standard is 900mm MDF)
4. Check that drawer boxes use quality joinery (recommend dovetail or finger joint)
5. Confirm finish compatibility with wood species selected
6. Calculate assembly complexity score (1=simple kit, 5=master craftsman)
Output: APROVADO / REVISÃO + adjustments list
```
